# Contributing to tpt-raglite

Thanks for helping. This project is small and aims to stay that way: prefer a change that is easy to read and easy to test over a clever one.

## Setup

1. Install Rust (stable), Python 3.9 or newer, and gcc or clang.
2. Download the model files:
   ```bash
   bash scripts/fetch_model.sh          # Windows: powershell -File scripts/fetch_model.ps1
   ```
3. Build and test:
   ```bash
   cargo test --workspace
   ```

With [`just`](https://github.com/casey/just) installed, `just setup`, `just test`, and `just demo` run the same steps (see `justfile`).

On Windows, the ONNX Runtime binaries need a current Visual Studio 2022 toolset. See the README troubleshooting section.

## Before you open a pull request

CI runs these, and a pull request needs them to pass:

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
bash tpt-rag-ffi/tests/run_c_integration.sh   # when the C ABI changes
```

If you change the C ABI, regenerate the header and commit it:

```bash
cbindgen --config tpt-rag-ffi/cbindgen.toml --crate tpt-rag-ffi --output tpt_raglite.h
```

CI fails if the committed `tpt_raglite.h` differs from the generated one. The pinned cbindgen version is 0.27.0.

For Python changes, also run `maturin develop` in `tpt-rag-py/` and `pytest tpt-rag-py/tests`.

## Guidelines

- **Tests**: add a test for each bug fix. Unit tests go next to the code. Tests that need the model go in `tpt-rag-core/tests/integration.rs`.
- **Errors**: return `RagError`. Do not panic across the C boundary; the FFI wraps each entry point in `catch_unwind`, but a panic is still a bug.
- **Persistence**: any change that writes to the index or metadata must keep them consistent after a crash. Look at how `ingest` and `open_with_config` do it, and add a test that reopens the database.
- **Comments**: explain why, not what. Match the density of the file you are editing.
- **Dependencies**: justify new crates in the pull request. Prefer what is already in the tree.

## Layout

```
tpt-rag-core/   engine: parsers, chunker, tokenizer, embeddings, reranker, HNSW, SQLite store
tpt-rag-ffi/    C ABI; header generated by cbindgen
tpt-rag-py/     Python package (PyO3 + maturin)
tpt-rag-wasm/   WebAssembly wrapper (experimental)
examples/       C and Python examples
scripts/        model download
todo.md         the project checklist, with the review findings and their status
```
