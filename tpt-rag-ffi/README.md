# tpt-rag-ffi

The C ABI for tpt-raglite. It builds a shared library (`tpt_rag_ffi.dll`, `libtpt_rag_ffi.so`, or `libtpt_rag_ffi.dylib`) and a static library, and it generates the C header `tpt_raglite.h`. Any language that can call C can use the engine through it.

The engine itself is [`tpt-rag-core`](../tpt-rag-core/). This crate adds no behaviour of its own. It adds the calling convention: opaque handles, error codes, caller-freed results, and a panic boundary, so a Rust panic never unwinds into C.

> **Status: pre-release (0.1.0).** Build from source. The header is generated, so it changes when the ABI changes.

## Build

Requirements: stable Rust, and a C compiler to use the library. Fetch the model first, because the library needs it at run time:

```bash
bash scripts/fetch_model.sh                       # Windows: powershell -File scripts/fetch_model.ps1
cargo build --release -p tpt-rag-ffi
```

Outputs, in `target/release/`:

| Platform | Shared library | Static library |
|---|---|---|
| Windows | `tpt_rag_ffi.dll` (with `tpt_rag_ffi.dll.lib` for linking) | `tpt_rag_ffi.lib` |
| Linux | `libtpt_rag_ffi.so` | `libtpt_rag_ffi.a` |
| macOS | `libtpt_rag_ffi.dylib` | `libtpt_rag_ffi.a` |

Compile a program against it (Linux and macOS, from the repository root):

```bash
gcc -Wall -Wextra -I. my_app.c -Ltarget/release -ltpt_rag_ffi -o my_app
LD_LIBRARY_PATH=target/release ./my_app
```

On Windows with MSVC, link `tpt_rag_ffi.dll.lib` and keep `tpt_rag_ffi.dll` next to the executable or on `PATH`.

## The header

`tpt_raglite.h` is generated by cbindgen during the build (`build.rs`, configured by `cbindgen.toml`). A copy is committed at the repository root, so C projects can include it without a Rust toolchain. Do not edit it by hand. Regenerate it by building the crate.

Include it like this:

```c
#include "tpt_raglite.h"
```

## Conventions

- **Handles are opaque.** `TptRagHandle *` comes from `tpt_rag_create` or `tpt_rag_create_with_config` and is released with `tpt_rag_destroy`. Do not dereference it.
- **Functions that do work return `TptRagError`.** `TptRagOk` is `0`. Anything else is a failure, and `tpt_rag_last_error()` describes it.
- **Creation returns a pointer.** `tpt_rag_create` and `tpt_rag_create_with_config` return `NULL` on failure. Check the pointer, then call `tpt_rag_last_error()`.
- **Error text is per thread.** `tpt_rag_last_error()` returns a pointer valid until the next call on the same thread. Copy it if you need it later. It is `NULL` if the last call succeeded.
- **Strings are UTF-8, NUL-terminated.** Results are returned as C strings you do not own; see [Memory ownership](#memory-ownership).
- **Panics do not cross the boundary.** Each entry point catches a Rust panic and returns `TptRagErrInternal`.

## Examples

These are complete, and each compiles against the header with `-Wall -Wextra -Werror`. The repository's [`examples/c_basic.c`](../examples/c_basic.c) is the shortest one, and CI compiles and runs it.

### 1. Ingest files and search

Ingest a folder's worth of files by path, with tags, then query. `tpt_rag_add_file` takes one file per call, so a directory is a loop over whatever listing your platform provides.

```c
#include <stdio.h>
#include "tpt_raglite.h"

int main(void) {
    TptRagHandle *rag = tpt_rag_create("./kb");
    if (!rag) {
        fprintf(stderr, "open failed: %s\n", tpt_rag_last_error());
        return 1;
    }

    const char *tags[] = {"docs", "ops"};
    TptRagError err = tpt_rag_add_file(rag, "docs/runbook.md", tags, 2);
    if (err != TptRagOk) {
        fprintf(stderr, "add failed (%d): %s\n", err, tpt_rag_last_error());
    }

    TptRagResult *results = NULL;
    size_t count = 0;
    err = tpt_rag_query(rag, "how do I rotate the key", 3, &results, &count);
    if (err != TptRagOk) {
        fprintf(stderr, "query failed (%d): %s\n", err, tpt_rag_last_error());
    } else {
        for (size_t i = 0; i < count; i++) {
            printf("[%.2f] %s (%s)\n", results[i].score, results[i].source, results[i].tags);
            printf("    %s\n", results[i].text);
        }
    }

    tpt_rag_free_results(results, count); /* safe on NULL and on zero results */
    tpt_rag_flush(rag);                   /* write the index now; errors are visible here */
    tpt_rag_destroy(rag);
    return 0;
}
```

### 2. Choose a ranking method

Hybrid search takes an `alpha` (the vector weight, from 0 to 1). Reranked search takes how many vector candidates to rescore. Both return the same result struct, so one printing function serves both.

```c
#include <stdio.h>
#include "tpt_raglite.h"

static void print_results(const char *label, TptRagResult *results, size_t count) {
    printf("%s (%zu)\n", label, count);
    for (size_t i = 0; i < count; i++) {
        printf("  [%.3f] %s\n", results[i].score, results[i].source);
    }
}

void compare_rankings(TptRagHandle *rag, const char *question) {
    TptRagResult *results = NULL;
    size_t count = 0;
    TptRagError err;

    /* alpha 0.5 weights vectors and keywords equally. */
    err = tpt_rag_query_hybrid(rag, question, 5, 0.5f, &results, &count);
    if (err == TptRagOk) {
        print_results("hybrid", results, count);
        tpt_rag_free_results(results, count);
    } else {
        fprintf(stderr, "hybrid failed (%d): %s\n", err, tpt_rag_last_error());
    }

    /* Needs the reranker model. Without it this returns TptRagErrInternal. */
    results = NULL;
    count = 0;
    err = tpt_rag_query_reranked(rag, question, 5, 20, &results, &count);
    if (err == TptRagOk) {
        print_results("reranked", results, count);
        tpt_rag_free_results(results, count);
    } else {
        fprintf(stderr, "rerank unavailable (%d): %s\n", err, tpt_rag_last_error());
    }
}
```

### 3. Open with custom settings

Start from `tpt_rag_default_config()` and change only the fields you need. A `NULL` `model_path` uses the normal lookup order.

```c
#include <stdio.h>
#include "tpt_raglite.h"

TptRagHandle *open_tuned(const char *db_path, const char *model_path) {
    TptRagConfig config = tpt_rag_default_config();
    config.model_path = model_path;   /* NULL means: use the usual lookup order */
    config.ef_search = 200;           /* more accurate search, a little slower */
    config.window_size = 256;         /* words per chunk */
    config.overlap = 32;              /* must stay below window_size */

    TptRagHandle *rag = tpt_rag_create_with_config(db_path, &config);
    if (!rag) {
        fprintf(stderr, "open failed: %s\n", tpt_rag_last_error());
    }
    return rag;
}
```

`config` is a plain struct, so it can live on the stack and be reused for several opens.

### 4. Add text, then delete a source

`tpt_rag_add_text` stores a string under no source label, so it can be found but not removed by source. For text you may need to delete, add it as a file, or use `tpt_rag_add_file` on a temporary file.

```c
#include <stdio.h>
#include "tpt_raglite.h"

void remove_source(TptRagHandle *rag, const char *source) {
    size_t deleted = 0;
    TptRagError err = tpt_rag_delete_document(rag, source, &deleted);
    if (err != TptRagOk) {
        fprintf(stderr, "delete failed (%d): %s\n", err, tpt_rag_last_error());
        return;
    }
    printf("removed %zu chunk(s) from %s\n", deleted, source);
}
```

`deleted_out` may be `NULL` if you do not need the count.

### 5. Handle failures by code

Map each error to what your program should do. Keep the message for logs, and do not rely on its wording.

```c
#include <stdio.h>
#include "tpt_raglite.h"

/* Returns 1 if the file was added, 0 if it was skipped, -1 on a fatal error. */
int ingest_one(TptRagHandle *rag, const char *path) {
    const char *tags[] = {"docs"};
    TptRagError err = tpt_rag_add_file(rag, path, tags, 1);

    switch (err) {
    case TptRagOk:
        return 1;
    case TptRagErrEmptyDoc:
        /* A scanned PDF or an empty file. Skip it, and run OCR on it if it matters. */
        fprintf(stderr, "skipped %s: no text\n", path);
        return 0;
    case TptRagErrUnsupported:
        fprintf(stderr, "skipped %s: %s\n", path, tpt_rag_last_error());
        return 0;
    case TptRagErrIo:
    case TptRagErrSqlite:
    case TptRagErrOnnx:
    case TptRagErrInvalidArg:
    case TptRagErrInternal:
    default:
        fprintf(stderr, "fatal (%d) on %s: %s\n", err, path, tpt_rag_last_error());
        return -1;
    }
}
```

### 6. Clean up on every path

Acquire resources in order and release them in reverse, with one exit point. This avoids leaking the handle when an early step fails:

```c
#include <stdio.h>
#include "tpt_raglite.h"

int answer(const char *db, const char *question) {
    int status = 1;
    TptRagHandle *rag = NULL;
    TptRagResult *results = NULL;
    size_t count = 0;

    rag = tpt_rag_create(db);
    if (!rag) {
        fprintf(stderr, "open failed: %s\n", tpt_rag_last_error());
        goto done;
    }

    if (tpt_rag_query(rag, question, 3, &results, &count) != TptRagOk) {
        fprintf(stderr, "query failed: %s\n", tpt_rag_last_error());
        goto done;
    }

    for (size_t i = 0; i < count; i++) {
        printf("%s\n", results[i].text);
    }
    status = 0;

done:
    tpt_rag_free_results(results, count);   /* NULL is accepted */
    tpt_rag_destroy(rag);                   /* NULL is accepted */
    return status;
}
```

Use `tpt_rag_destroy` on the handle even when you did not flush. Dropping the handle writes the index, but a flush is the only way to see an error.

## Function reference

| Function | Purpose |
|---|---|
| `tpt_rag_default_config()` | Returns `TptRagConfig` with the defaults. `model_path` is `NULL` |
| `tpt_rag_create(path)` | Opens or creates the database folder at `path` |
| `tpt_rag_create_with_config(path, &config)` | As above, with the settings in `config` |
| `tpt_rag_destroy(handle)` | Releases the handle. `NULL` is accepted |
| `tpt_rag_add_file(handle, path, tags, tag_count)` | Ingests one file. Re-adding replaces its chunks |
| `tpt_rag_add_text(handle, text)` | Ingests a string, stored under the source `inline` |
| `tpt_rag_query(handle, text, top_k, &results, &count)` | Vector search |
| `tpt_rag_query_hybrid(handle, text, top_k, alpha, &results, &count)` | Vector and keyword search. `alpha` is the vector weight, 0 to 1 |
| `tpt_rag_query_reranked(handle, text, top_k, rerank_top_n, &results, &count)` | Vector search, then the cross-encoder. Needs the reranker |
| `tpt_rag_delete_document(handle, source, &deleted)` | Removes every chunk from `source`. `deleted` may be `NULL` |
| `tpt_rag_flush(handle)` | Writes the index to disk and reports any error |
| `tpt_rag_free_results(results, count)` | Frees a result array from a query. `NULL` is accepted |
| `tpt_rag_last_error()` | Message for the last failure on this thread, or `NULL` |
| `tpt_rag_version()` | Library version, as a static string. Do not free it |

The FFI does not expose `neighbors`, `query_diverse`, `query_filtered`, folder sync, or stats yet. Use the [Rust API](../tpt-rag-core/README.md) or the [`raglite` command](../tpt-rag-core/README.md#the-raglite-command) for those.

### `TptRagResult`

| Field | Type | Meaning |
|---|---|---|
| `score` | `float` | Relevance. The scale depends on the query method (see the core README) |
| `text` | `char *` | The chunk text |
| `source` | `char *` | The source path or label |
| `tags` | `char *` | The chunk's tags, joined with commas. Empty when there are none |

`TptRagConfig` has `model_path`, `m`, `ef_construction`, `ef_search`, `window_size`, `overlap`, `flush_every`, and `reembed_on_model_change`. The field meanings match [`RagConfig`](../tpt-rag-core/README.md#configuration).

## Error codes

| Code | Value | Meaning |
|---|---|---|
| `TptRagOk` | 0 | Success |
| `TptRagErrInvalidArg` | -1 | A required pointer was `NULL`, a string was not UTF-8, or a setting is out of range |
| `TptRagErrIo` | -2 | A file could not be read or written |
| `TptRagErrSqlite` | -3 | The metadata store returned an error |
| `TptRagErrOnnx` | -4 | ONNX Runtime failed to load or run the embedding model |
| `TptRagErrEmptyDoc` | -5 | The file has no text, such as a scanned PDF |
| `TptRagErrUnsupported` | -6 | No parser handles the file's extension |
| `TptRagErrInternal` | -7 | Anything else: a missing or invalid model file (including the reranker), a corrupt index, a caught panic |

## Memory ownership

The rules are simple, and breaking them causes crashes:

- **Results belong to the caller.** Free the array with `tpt_rag_free_results(results, count)`, once, with the same `count` the query returned. Do not free `text`, `source` or `tags` one at a time.
- **Free only what the library gave you.** Free results with `tpt_rag_free_results`, not `free()`. The library allocates them with Rust's allocator.
- **Error and version strings belong to the library.** Do not free `tpt_rag_last_error()` or `tpt_rag_version()`. Copy the error text if you keep it.
- **Input strings stay yours.** The library reads them during the call and does not keep them. Your `char *` arguments can be freed as soon as the call returns.
- **A handle is freed once.** Calling `tpt_rag_destroy` twice on the same pointer is undefined behaviour.

## Threads

A handle is not safe to share between threads without your own lock. Use one handle per thread, or put a mutex around each call. `tpt_rag_last_error()` is per thread, so read it on the thread that made the failing call.

## Testing

The C tests run on Linux, with the model files present:

```bash
bash tpt-rag-ffi/tests/run_c_integration.sh
```

The script builds the library, compiles `tpt-rag-ffi/tests/c_integration.c` and `examples/c_basic.c` with `-Werror`, and runs both. The crate has no Rust unit tests of its own, so the C tests are what exercise the boundary.
